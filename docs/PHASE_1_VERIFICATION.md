# Public AZINHACK verification summary

The 77-test figure from the **private** Schema checkpoint is historical; it is not evidence of a current production deployment. This public hackathon snapshot has source, migrations, UI, TinyFish adapter and tests. Independent full tests/build are required for each commit.

**Verified in source:** owner-scoped row-level security, account-based quotas, separate TinyFish server keys and allowlists, consent controls, helper tests, a distinct private Sites versus customer architecture.

**Needs live verification:** email signup/recovery, authenticated customer host, migrations installed, provider-keyed TinyFish extraction and save/reopen, AI citation quality, two-account isolation, alerts, deletion, provider backup restoration and scale. The original private project's credentials and user records are not included.
